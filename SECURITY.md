# Segurança

## Versões com suporte

Só a versão mais recente recebe correções. A ilha se atualiza sozinha, então basta mantê-la aberta
por alguns minutos (a versão aparece no rodapé do painel).

## Como relatar uma falha de segurança

**Não abra uma issue pública** para falhas de segurança. Use o
[relato privado de vulnerabilidades](https://github.com/Igorms27/Islandbar/security/advisories/new)
do GitHub, com uma descrição do problema e, se possível, os passos para reproduzi-lo.
